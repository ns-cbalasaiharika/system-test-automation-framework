# Downloader Single Fault Scenarios

Single fault injection scenarios under load for Downloader service.

## Naming

- Prefix: `dl-sf`
- Example: `dl-sf01-storage-slow.ts`

## Suggested Scenarios

| ID | Name | Description |
|----|------|-------------|
| DL-SF01 | Storage Slow | Storage latency injection |
| DL-SF02 | CDN Failover | CDN node failure |

## Reference

- Config: `config/scenarios/downloader/dl-sf*.yaml`
